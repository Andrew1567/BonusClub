# FleetMaintenance
Навчальний проєкт з дисципліни «Конструювання програмного забезпечення». 
Варіант № 16: обслуговування й ремонт автопарку.

## Склад рішення
* `FleetMaintenance.Core` — логіка предметної області (бібліотека)
* `FleetMaintenance.App` — консольний застосунок (введення, виведення)

## Вимоги
.NET SDK 8.0 або новіший, Git.

## Складання та запуск
```bash
dotnet build
dotnet run --project FleetMaintenance.App
