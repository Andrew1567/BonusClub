# Стандарт кодування проєкту FleetMaintenance

## 1. Загальні положення
Цей документ описує стандарти написання коду для проєкту FleetMaintenance. Усі розробники зобов'язані дотримуватися цих правил.

## 2. Іменування
| Сутність | Конвенція | Приклад | Антиприклад |
| :--- | :--- | :--- | :--- |
| Клас, запис | PascalCase, іменник | ServiceLine | serviceline |
| Інтерфейс | I + PascalCase | IVehicleRepository | Repository |
| Метод | PascalCase, дієслово | CalculateTotal | calc |
| Властивість | PascalCase, іменник | HourlyRate | GetHourlyRate |
| Приватне поле | _ + camelCase | _lines | m_Lines |
| Локальна змінна | camelCase | totalAmount | ta |
| Константа | PascalCase | MaxLineCount | MAX_LINES |
| Перелічення | PascalCase однина | MaintenanceStatus | MaintenanceStatuses |

## 3. Форматування
1. Відступ — 4 пробіли; табуляція заборонена.
2. Довжина рядка — не більше ніж 100 символів.
3. Фігурні дужки — стиль Allman, обов'язкові навіть для однієї інструкції в тілі if.
4. Між членами класу — рівно один порожній рядок.
5. Директиви using на початку файлу, системні — перші, невживані видаляються.
6. Простір імен — файлового рівня (namespace X;).

## 4. Коментарі та документація
Коментарі повинні пояснювати причину ("чому"), а не дублювати код ("що").

// погано: коментар переказує код
// додаємо нову лінію послуг
_lines.Add(line);

// Округлюємо години вгору, оскільки мінімальний час оплати - 1 година
